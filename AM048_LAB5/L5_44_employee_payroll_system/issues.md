# Static Code Analysis & Remediation Issues Log

Repository: `L5_44_employee_payroll_system`
Target File: `employee_payroll_system.py`

| Issue | Type | Line(s) | Description | Fix Approach |
| :--- | :--- | :--- | :--- | :--- |
| Command Injection via `os.system` (`B605`) | Security (High) | 58 | `export_payroll_sheet()` invoked `os.system(f"echo Payroll summary exported to: {filename}")`, allowing shell command injection if `filename` contains shell metacharacters. | Removed `os.system()` and printed the export confirmation directly with Python `print()`. |
| Weak Hash Algorithm MD5 (`B324`) | Security (High) | 47 | `generate_employee_hash()` used `hashlib.md5()`, which is cryptographically broken and susceptible to collision attacks. | Replaced `hashlib.md5` with `hashlib.sha256` using explicit UTF-8 encoding. |
| Hardcoded Payroll Key & Secret Exposure | Security / Logic (High, Manual) | 62, 70 | A master credential (`"HR_PAYROLL_MASTER_SECRET_2026"`) was hardcoded in source and printed in plaintext to standard output. | Removed the hardcoded literal; load `PAYROLL_KEY` via `os.environ.get("PAYROLL_KEY")` and print only a boolean configuration status (`"configured"` / `"not set"`). |
| Arbitrary Code Execution via `eval()` (`B307`, `W0123`) | Security (Medium) | 42 | `compute_net_salary()` evaluated `deduction_expr` directly with `eval()`, permitting arbitrary Python execution, and left `base` unused (`W0612`, `F841`). | Replaced `eval()` with `ast.parse(..., mode="eval")` and a strict recursive AST evaluator (`_eval_ast_node`) permitting only numeric constants, safe variable names (`base`, `tax_rate`), unary `+`/`-`, and binary `+`/`-`/`*`/`/` (guarding division by zero). |
| Insecure PRNG for Payroll Token (`B311`) | Security (Low) | 51 | `generate_payroll_token()` used `random.randint(1000, 9999)`, which uses Mersenne Twister and is predictable. | Replaced `random.randint` with cryptographically secure `1000 + secrets.randbelow(9000)`. |
| Silent Broad Exception Swallowing (`B110`, `W0702`, `E722`) | Security / Bug (Low) | 26 | `deduct_penalty()` wrapped subtraction in `except: pass`, hiding errors like `TypeError`, `KeyError`, or `None` access instead of handling invalid inputs. | Removed `try/except: pass`; validated `emp_id` membership, validated `penalty` via `_is_valid_amount()`, checked sufficient balance (`penalty <= base_salary`), and returned `False` cleanly. |
| Missing Negative / Type Validation on Bonus & Penalty | Logic / Integrity (Medium, Manual) | 15-28 | `process_salary()` and `deduct_penalty()` did not validate amounts: negative `penalty` increased salary, negative `bonus` decreased salary, and booleans/non-finite floats passed type checks. | Added shared `_is_number()` and `_is_valid_amount()` helpers rejecting `bool`, negative numbers, `NaN`, and `inf`, and rejecting penalties exceeding `base_salary`. |
| Mutable Default Argument (`W0102`) | Bug / Quality | 15 | `processSalary(emp_id, bonus, transaction_logs=[])` reused a single shared list across calls when omitted. | Changed default to `transaction_logs=None` and initialized `transaction_logs = []` inside the function body. |
| `== None` Singleton Comparison & Redundant `if/else` (`C0121`, `E711`, `R1703`, `R1705`) | Code Quality / Style | 32-37 | `check_bonus_eligibility()` checked `emp == None`, unnecessarily used `if ...: return True else: return False`, and assigned unused `statutory_buffer = 0.0` (`W0612`, `F841`). | Used `payroll_records.get(emp_id)`, checked `if record is None:`, removed unused `statutory_buffer`, and directly returned `record["base_salary"] >= min_base`. |
| File Handle Resource Leak & Missing Encoding (`R1732`, `W1514`) | Bug / Resource | 55 | `open(filename, "w")` lacked explicit encoding and context manager, risking unclosed file descriptors on write failure. | Switched to `with open(filename, "w", encoding="utf-8") as payroll_file:` writing formatted JSON safely. |
| Side Effects on Module Import | Logic / Bug (Manual) | 73 | Top-level `main()` executed unconditionally when importing `employee_payroll_system` for testing or reuse. | Wrapped `main()` execution in `if __name__ == "__main__":`. |
| Unused Import & Legacy Formatting (`W0611`, `F401`, `C0103`, `C0209`, `C0116`, `E501`, `C0304`, `W292`) | Style / Maintainability | 6, 15, 19, 73 | Unused `import math`, camelCase `processSalary`, `%`-formatting, missing module/function docstrings, lines > 79 chars (`E501`), and missing trailing newline (`C0304`/`W292`). | Removed unused `math`, renamed `process_salary`, used f-strings, added docstrings everywhere, wrapped all lines to <= 79 chars for PEP 8 / Flake8 compliance, and added a final newline. |
